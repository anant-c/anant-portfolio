# anant-portfolio

Personal portfolio for Anant Chaudhary.

Built with Vite, React 19, Tailwind CSS v4, react-router-dom, Lenis smooth scroll, and the Jura font.

## Scripts

- `npm run dev`: Start local development server with HMR
- `npm run build`: Build production assets to `dist/`
- `npm run lint`: Run ESLint checks
- `npm run preview`: Locally preview production build

## Architecture and Content Model

All portfolio content is decoupled from layout. Data lives in JavaScript objects in `src/data/*.js` and in `public/learn/index.json`. React components are strictly presentational; they import data and render UI. Adding or updating content requires modifying data objects, never touching JSX structure or styling.

## Adding Things

### Adding a Project

File: `src/data/projects.js`
Asset: Place project image or preview graphic under `public/assets/` (any aspect ratio: it is shown in a fixed 16:9 frame, fitted inside without cropping)

1. Place image in `public/assets/<filename>` (SVG, PNG, or JPG).
2. Append a new project object to the `projects` array in `src/data/projects.js`.
3. Set `featured: true` to display it on the Home page (`/`), or `false` to display it only on the Projects page (`/projects`).
4. Set `status: "online"` or `"offline"` to toggle the green/gray pulsing status indicator.

Object shape:
```javascript
{
  id: "project-slug",
  title: "Project Title",
  image: "/assets/project-image.png",
  imageAlt: "Project Alt Description",
  status: "online", // "online" or "offline"
  tags: ["FastAPI", "React", "Docker"],
  description: "Plain text summary of what the project does and its architecture.",
  github: "https://github.com/anant-c/repo-name",
  live: "https://project.mrsons.online", // or null if no live demo
  featured: true, // boolean: true displays on Home page, false on /projects only
}
```

### Adding a Blog Post

File: `src/data/blogs.js`

1. Append a blog post object to the `blogs` array in `src/data/blogs.js`.
2. The `url` property is optional:
   - When populated with a live link (e.g. Hashnode article URL), clicking the card opens the URL.
   - When empty (`""` or `null`), the card renders as a static block and displays secondary links from the `links` array (such as companion GitHub repositories or skills).

Object shape:
```javascript
{
  slug: "article-slug",
  title: "Article Title",
  date: "YYYY-MM-DD",
  series: "Ship It Safe",
  description: "Plain text summary of the article topic.",
  tags: ["Tag1", "Tag2"],
  url: "", // optional: Hashnode or external article URL
  links: [ // optional: displayed if url is empty
    {
      label: "Skill on GitHub",
      url: "https://github.com/anant-c/skills",
    },
  ],
}
```

### Learn Section

The `/learn` route is an index of curated notes on video playlists and conference talks.

#### How It Works

- The React page at `/learn` (`src/components/Learn.jsx`) fetches `public/learn/index.json` at runtime and renders an overview card list.
- Each card links to a static, self-contained HTML page tree located at `public/learn/<slug>/`.
- Inside `public/learn/<slug>/`:
  - `index.html`: overview and table of contents
  - per-video pages (e.g. `01-introduction.html`)
  - `style.css`: self-contained CSS styles
  - `cover.svg`: visual card cover graphic
- These static pages are plain HTML and CSS. They require no React runtime, do not use client-side hydration, and cost nothing in the JavaScript bundle size.
- The static HTML tree is generated by the separate `ytnotes` CLI (`ytnotes (separate repo, lives at ~/code/ytnotes on the VPS)`) and copied into `public/learn/<slug>/` via `ytnotes publish`. Note: `https://github.com/anant-c/ytnotes` is not published yet.

#### index.json Schema

Each entry in `public/learn/index.json` matches this schema:

```json
{
  "slug": "playlist-or-video-slug",
  "title": "Title of Note Collection",
  "kind": "playlist",
  "channel": "Channel or Creator Name",
  "source_url": "https://www.youtube.com/playlist?list=...",
  "videos": 10,
  "duration_min": 150,
  "added": "2026-10-01",
  "summary": "Concise summary of topics covered in this note set.",
  "tags": ["Topic1", "Topic2"],
  "accent": "#3b82f6",
  "cover": "cover.svg",
  "unlisted": false
}
```

Field reference:
- `slug` (string, required): Lowercase alphanumeric and hyphens (`^[a-z0-9-]+$`). Determines directory name at `public/learn/<slug>/`.
- `title` (string, required): Display title of the note collection.
- `kind` (string, required): `"playlist"` (rendered as "Playlist" tag) or `"video"` (rendered as "Video" tag).
- `channel` (string, required): YouTube channel or presenter name.
- `source_url` (string, required): Canonical URL to the original YouTube playlist or video.
- `videos` (number, required): Total number of videos included in the notes.
- `duration_min` (number, required): Total runtime in minutes; formatted into readable hours/minutes.
- `added` (string, required): Date added in `YYYY-MM-DD` format; formatted as "added Mon YYYY".
- `summary` (string, required): Brief synopsis of the collection.
- `tags` (array of strings, required): List of topic tags rendered as chips.
- `accent` (string, optional): Hex color code applied as a left border highlight on the card.
- `cover` (string, optional): Cover asset filename relative to `public/learn/<slug>/`.
- `unlisted` (boolean, optional): When `true`, filters the entry out of the `/learn` list.

#### Unlisting and Deleting Items

- **Unlist an item**: Set `"unlisted": true` on the item in `public/learn/index.json`. The card will no longer appear in the `/learn` page directory, but the static pages under `public/learn/<slug>/` remain reachable by direct URL.
- **Delete an item**: Remove the item object from `public/learn/index.json`, then delete the folder `public/learn/<slug>/`.
